# TicketPilot 前端文件说明

当前前端采用 React、TypeScript 和 Vite。源码、样式和支持注释的配置文件已在文件开头说明“文件职责、作用与配合、使用位置、边界”，阅读一个文件时先看这几行。

## 按什么顺序理解目录

浏览器从 `index.html` 加载 `src/main.tsx`，再进入 `src/app/App.tsx`。`app/providers.tsx` 提供查询客户端与登录状态，`app/router.tsx` 根据地址选择布局和页面。`layouts/` 管理共用外壳，`features/` 管理登录、入库等业务，`shared/` 提供公共请求与基础样式。

## 不适合直接写代码注释的文件

| 文件或目录 | 负责什么 | 阅读时注意 |
| --- | --- | --- |
| `package.json` | 声明前端依赖，以及 dev、build、lint 等 npm 命令 | 属于严格 JSON，不插入 `//` 或 `/* */` 注释。 |
| `package-lock.json` | 锁定实际依赖版本及依赖关系，让安装结果可重复 | 由 npm 管理；通常不手动修改或插入注释。 |
| `.oxlintrc.json` | 配置 Oxlint 检查，例如 React Hook 调用规则 | 保持现有 JSON 配置，不为添加说明改变检查规则。 |
| `public/favicon.svg` | 提供浏览器标签页的小图标 | 当前由 index.html 引用；图片和矢量资源不承担业务逻辑。 |
| `public/icons.svg` | 保留的图标资源文件 | 当前源码没有引用，不能据此认为图标已接入界面。 |
| `src/assets/` | 保留 Vite、React 等初始示例素材 | 当前源码没有引用这些素材；无需为添加说明修改图片内容。 |
| `node_modules/` | 存放安装好的第三方依赖 | 自动生成，不给依赖源码逐个添加教学注释。 |
| `dist/` | 存放生产构建产物 | 由构建生成，源码修改后重新构建，不直接编辑。 |

`tsconfig*.json` 是例外：TypeScript 按支持注释的配置格式读取它们，所以文件头可以保留中文块注释。它们的用途也已写在各自文件头。

## 后续文件说明约定

每个新文件先写中文文件头，再写实现；函数用途和参数含义继续注释。已有文件优先做局部修改，不覆盖已经写好的业务代码。更完整的结构与界面约定见仓库根目录的 `FRONTEND_PLAN.md`。

## 本地运行与检查

在 frontend 目录执行：

```powershell
npm ci
npm run dev
```

已安装依赖时直接运行 npm run dev。浏览器访问终端实际显示的 Local 地址；端口被占用时可能变化。

当前开发代理将 /v1 请求转发到 http://127.0.0.1:8000，因此需要先运行现有 FastAPI 后端。知识入库还需要对应数据库、Worker 和解析/向量服务；Agent 问答需要模型服务。Vite 不会自动启动这些服务。

```powershell
npm run build
npm run lint
```

build 检查 TypeScript 并生成 dist；lint 做静态检查。这两项通过不能代替真实接口或浏览器验收。部署时需要为 /v1 配置实际后端转发，并为前端路由配置入口回退；不要将开发代理当作部署配置。

## 当前业务与公共代码

已注册登录、入库、入库任务详情、知识文档列表、当前文档详情、历史版本详情、Agent 问答、工单列表、工单创建、工单详情共 10 个页面。

工单模块的 cache.ts 统一四个写操作的缓存刷新，按账号和角色隔离；TicketEditor.module.css 供状态和处理人编辑组件共享。删除确认已接入详情页，主管和管理员可见。

## 检查打包后的本机预览

先运行 npm run build；再在单独终端运行 npm run preview -- --host 127.0.0.1 --port 4173 --strictPort；服务启动后运行 npm run check:preview。默认检查 http://127.0.0.1:4173/；也可以通过 npm run check:preview -- http://127.0.0.1:其他端口/ 指定另一本机预览端口。

该脚本只发GET请求，检查页面入口回退、全部构建资源与入口引用资源的文件内容/MIME类型，以及未登录的/v1/tickets代理401响应。当前10条页面地址、26个构建资源加favicon共27个资源检查通过。它不执行浏览器渲染或业务写操作；后端应在8000端口运行。

预览读取dist，源码修改后需重新构建。4173与5173属于不同来源，浏览器中的登录令牌存储相互隔离，预览页面可能需要重新登录。正式部署仍需独立配置/v1转发及前端入口回退。
